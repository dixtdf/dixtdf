### 项目

| 项目 | 做什么 |
| :--- | :--- |
| [**abdm-server**](https://github.com/dixtdf/abdm-server) | 自托管多连接下载管理器，提供 Web UI 与 Docker 部署。 |
| [**clear-file**](https://github.com/dixtdf/clear-file) | 面向 NAS 和服务器的文件清理、磁盘分析工具。 |
